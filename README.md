A Python program that writes one deadpan one-star review of gravity — the service is flawless and constant, and that is the complaint: toast lands butter-down, phones land face-down — to /output/entry.txt. The line is UTF-8 text of 154 characters, within the bounty's 160-character limit. Deterministic and offline: no network use.

## Run it

```sh
python3 main.py
```

Writes the line to /output/entry.txt (or ./output/entry.txt when /output is not writable).
